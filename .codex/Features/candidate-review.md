# Candidate review

Цель: принять и сохранить редакционные решения по кандидатам, ручные исправления и подавления, не переписывая доказательства.

`candidate-review/review-decisions` — контракты кейса, решения, ручного наблюдения и подавления; чистые переходы; прикладной сервис и курсоры; PostgreSQL-персистенция; генератор контрактов ревью.

Цепочки:

Кандидат → кейс ревью → команда решения с ожидаемой ревизией → append-only решение → новая ревизия кандидата.

Ручное наблюдение → новая ревизия → применяется к кандидату по правилам перехода.

Подавление → ревизия подавления → активная область (discovery, normalization, export) → применяется к целям.

Границы:

- решения, ручные наблюдения и подавления — append-only доказательства; обновление и удаление отвергаются;
- конкурентность явная, через ожидаемые ревизии; устаревшая ревизия — конфликт, не молчаливая перезапись;
- worker gateway и прочие не-review deployables не зависят от `review_infrastructure`;
- оператор аутентифицирован; actor берётся только из аутентифицированной идентичности.

Философия: решение проверяющего — факт, который нельзя переписать. Повторное решение создаёт новую ревизию, а не изменяет прежнюю.
