# Campaign configuration

Цель: превратить авторские YAML в проверенную конфигурацию кампании и неизменяемый снапшот с каноническими digest'ами.

`campaign-config/authoring-inputs` — авторские YAML кампании (атрибуты, вида сущностей, география, таксономия, привязки источников, политики источников, профили нормализации), provenance границы и инструменты подготовки исходной географии.

`campaign-config/snapshot-compilation` — строгий разбор документов, проверка перекрёстных ссылок, каноникализация и digest'ы, запечатывание снапшота, DDL-контракт таблиц снапшота и CLI `collector`.

Цепочки:

Авторские файлы → allowlisted root → строгий разбор → проверка ссылок → канонический bundle + digest → запечатывание child-first/root-last → неизменяемые записи.

Авторские файлы → `collector config validate` → готовность кампании или явные блокеры.

Границы:

- авторские файлы — единственный владелец входа; runtime использует неизменяемый снапшот и его digest, mutable Git-файлы не перечитываются как runtime-истина;
- `geography.py` участвует и в подготовке исходной географии, и в проверке покрытия при компиляции, поэтому входит в обе части;
- заблокированная готовность остаётся заблокированной; отсутствие артефакта границы не подменяется пустым успехом;
- барьер Берлина остаётся в данных кампании, не в платформенных пакетах.

Инварианты:

- ключ кампании и пути не выходят за allowlisted root; symlinks и неожидаемые файлы отклоняются;
- дублирующиеся YAML-ключи отклоняются; модели запрещают неизвестные поля и неявные обязательные значения;
- перекрёстные ссылки документов разрешаются ровно один раз; заголовки и строки manual seed явные;
- заданные профили нормализации входят в snapshot; binding ссылается на существующий профиль, target fields разрешены его policy и совместимы с типами атрибутов; профиль не выводится автоматически;
- `value_kind` допускается только для совместимого типа атрибута: `text` → `text`/`localized_text`, `boolean` → `boolean`, `url` → `url`, `email` → `email`, `phone` → `phone`, `structured_address` → `structured_address`, `money` → `money`, `string_set` → `set`; для `enum`, `external_reference`, `decimal`, `integer` и `measurement` сопоставление не выводится;
- канонические хеши стабильны и чувствительны к содержанию;
- полный bundle запечатывается одной транзакцией child-first/root-last;
- запечатанные записи конфигурации не принимают insert, update или delete;
- метаданные БД не имитируют артефакт объектного хранилища: runtime-writer отсутствует, пока владелец загрузки и верификации не реализован.

Философия: конфигурация — данные, не код; один канонический digest владеет идентичностью снапшота. Снапшот не правится после публикации и не подменяется молчаливым fallback'ом.
