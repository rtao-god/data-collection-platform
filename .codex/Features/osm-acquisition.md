# OSM acquisition

Цель: получить данные OpenStreetMap по настроенной рыночной области с сохранённым provenance.

`osm-acquisition/connector-and-worker` — строгие контракты запроса, планирование Overpass, сборка запроса, HTTP-исполнение, разбор ответа и хост OSM worker.

Цепочки:

Кампания + рыночная область → планирование запроса → Overpass query → HTTP → разбор ответа → raw артефакт + provenance.

Аренда `osm_fetch` → OSM worker → Worker Gateway → верифицированный артефакт → завершение.

Границы:

- worker изолирован по capability и не получает учётные данные PostgreSQL или объектного хранилища;
- ответ без распознанных сущностей не выдаётся за пустой успешный результат;
- границы Берлина остаются в конфигурации кампании, не в коннекторе;
- транспорт к арендам и артефактам идёт только через `source_connector_sdk`.

Философия: доказательство источника важнее объёма. Точный запрос и точный ответ связаны digest'ами, чтобы результат можно было перепроверить.

Tests: `connectors/osm_overpass/tests`, `apps/osm_worker/tests`.
